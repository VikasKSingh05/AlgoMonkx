# 🚀 AlgoMonkx

**AlgoMonkx** is a full-stack SaaS platform designed to help developers master **Data Structures & Algorithms (DSA)** and excel in **Competitive Programming**. It combines structured learning, curated problem-solving, live contests, analytics, and mentorship into one unified ecosystem.

---

## 🌟 Features

### 🧠 DSA Mastery Library

* 1000+ curated problems
* Categorized by:

  * Difficulty (Easy / Medium / Hard)
  * Topics (Arrays, Trees, Graphs, DP, etc.)
  * Patterns (Sliding Window, Backtracking, etc.)
* Detailed solutions:

  * Multiple approaches (Brute → Optimized)
  * Code in C++, Java, Python
  * Video explanations (optional)

---

### 🎯 Pattern-Based Learning

* High-yield patterns frequently asked in interviews
* Each pattern includes:

  * Explanation & intuition
  * Recognition strategies
  * Curated problem sets

### 🏋️ Training Grounds

* Structured learning paths:

  * Beginner

## ⚙️ Installation

### 1. Clone Repository

```bash
git clone https://github.com/vikasksingh05/algomonkx.git
cd algomonkx
```

### 2. Setup Frontend

```bash
cd client
npm install
npm run dev
```

### 3. Setup Backend

```bash
cd server
npm install
npm run dev
```

### 4. Environment Variables

Create `.env` files in both frontend & backend:

#### Example:

```
DATABASE_URL=
JWT_SECRET=
REDIS_URL=
GOOGLE_CLIENT_ID=
GITHUB_CLIENT_ID=
STRIPE_KEY=
```
